# 共创平台全面视觉升级设计

日期：2026-07-17

## 1. 目标

本次改造的目标不是改功能，而是在保留现有业务流和信息结构主干的前提下，把整套共创平台从“功能拼接的工具页”提升为“展示感更强、视觉更开阔的展厅化中控”。

用户已经确认的方向如下：

- 保留当前的浅色科技基调，不切到深色主界面。
- 全站统一优化，不只做局部按钮或卡片修饰。
- 工作台主页面也纳入升级范围。
- 工作台视觉应从“高密度操作台”向“展示感更强、空间更开阔”的方向拉。
- 登录页当前角色动效可以保留，但要压低卡通感，提升成更成熟的品牌装置感。
- 已优先修复工作台主预览区图片随窗口自适应的问题，本次视觉升级在此基础上继续推进。

## 2. 设计定位

### 2.1 视觉 Thesis

整体视觉定位为：

`浅色科技中控 + 工业设计展厅 + 克制的高级感`

界面应传达的感受：

- 干净
- 开阔
- 精密
- 冷静
- 有品牌识别但不过分装饰

### 2.2 交互 Thesis

交互层不增加新能力，而是通过视觉和结构顺序强化主次关系：

- 结果预览优先
- 关键操作次之
- 解释性信息和历史沉淀再次之

用户在任何页面都应快速看到：

1. 当前所在模块
2. 当前最重要的内容
3. 下一步能做什么

## 3. 视觉系统

### 3.1 颜色

保留浅色系统，但收紧为更统一的工业科技配色：

- 主背景：偏冷的浅灰蓝白
- 主表面：高透浅白
- 主文字：深 slate
- 主强调：冷工业蓝
- 次强调：青蓝高光
- 成功态：偏冷的绿色而非鲜艳绿
- 风险态：低饱和红

避免：

- 大面积紫色主导
- 高饱和渐变滥用
- 多重强强调色并存

### 3.2 材质与表面

全站表面采用三层关系：

1. 背景层
2. 浮层 / 壳层
3. 工作面板层

实现原则：

- 顶部壳层和关键弹窗可使用轻度玻璃感
- 常规操作区避免每块都重阴影
- 通过留白、边界、透明度和背景对比建立层次，而不是到处堆卡片

### 3.3 字体与层级

不更换当前中文系统字体链，但强化字号与层级秩序：

- 页面标题更明确
- 辅助说明缩短
- 统计数字与关键信息更突出
- 模块标签采用更统一的英文小标题 / 大写 tracking 风格

### 3.4 背景与纹理

全局背景不再是纯平色：

- 使用轻度网格纹理
- 顶部或角落加入弱光晕
- 让大块留白区域更有气氛，但不能喧宾夺主

## 4. 页面级改造

### 4.1 登录页

目标：从“左右分栏登录页”升级成“品牌入口页”。

改造内容：

- 左侧角色区域保留，但整体压低插画感，提升为品牌装置区。
- 左侧增加品牌标题、副标题和一句简短的系统说明。
- 背景不使用普通紫蓝渐变，而是改成更成熟的深蓝到冷青体系。
- 角色与背景光场融合，让角色更像品牌陈设的一部分。
- 右侧表单区采用更轻的高透白面板，边界更柔和，层次更精致。
- 输入框、错误提示、按钮统一为成熟产品语言。

不做：

- 不移除角色系统
- 不增加注册、找回密码等新流程

### 4.2 顶部壳层

目标：让壳层成为全站统一基座，而不是普通导航条。

改造内容：

- 顶部导航采用悬浮中枢条。
- 左侧为品牌标识、系统名、副标题。
- 中部为工作台 / 项目库 / 资产库切换。
- 右侧为用户信息与退出。
- 移动端保留横向稳定结构，不出现竖排压缩。

视觉重点：

- 圆角更统一
- 投影更轻
- 透明度更克制
- 减少“像 admin 面板”的感觉

### 4.3 工作台

目标：从操作台式布局升级为“预览主舞台 + 精简控制区 + 清晰状态区”的展示型工作台。

这是本次最重要的页面。

改造原则：

- 预览区成为视觉主角
- 左侧控制区减少碎片感
- 状态提示和结果信息不抢主预览
- 生成链路的阶段感更清晰

具体改造：

- 主预览区面积和留白更大
- 预览卡边界更轻，舞台感更强
- 控制区模块顺序重整：
  - 项目与场景
  - 参考资产
  - Prompt / 输入
  - 关键生成按钮
  - 状态信息
- 辅助信息块弱化装饰边框，强化逻辑分组
- “正在生成 / 失败 / 空态 / 本地预览”几种状态的视觉语言统一

可调整但不改变业务逻辑的结构：

- 左右列比例
- 标题与副标题层级
- 操作按钮排布
- 状态卡顺序
- 参考资产卡与 Prompt 卡的呈现方式

### 4.4 项目库

目标：更像项目陈列墙，而不是管理列表。

用户确认的新交互要求：

- 项目库首页只显示项目卡片
- 点击项目卡片后进入单独的项目历史版本页

首页改造：

- 项目卡片更强调封面图
- 项目名、版本数、更新时间更清晰
- 卡片整体更像作品封面而不是信息表

项目详情页改造：

- 顶部返回项目库
- 中部为版本列表
- 右侧为版本详情
- 版本详情强调结果图、Prompt、导出资产和状态

### 4.5 资产库

目标：从普通资产列表升级成定稿成果库。

改造内容：

- 顶部保留统计，但视觉更像成果面板
- 图像资产和 Prompt 资产分区明显
- 图像资产更偏陈列
- Prompt 资产更偏知识沉淀
- 添加资产弹窗保留现有能力，但视觉更统一、更轻

添加弹窗仍保留三种入口：

1. 从项目版本发布
2. 上传外部资产
3. 新建 Prompt 资产

## 5. 实施边界

本次只做视觉与结构层优化，不改业务能力。

### 5.1 会改

- 背景、配色、层级、圆角、阴影
- 页面留白与比例
- 模块顺序和视觉主次
- 弹窗、空态、统计卡、状态块统一
- 工作台内部布局比例和信息层级

### 5.2 不改

- 登录逻辑
- 工作台生成逻辑
- 版本生成逻辑
- 项目库 / 资产库业务定义
- 本地持久化结构
- 后端接口

## 6. 主要修改文件

本次实施预计主要涉及：

- `frontend/src/styles/index.css`

- `frontend/src/components/CoCreationAgentWorkspace.tsx`

## 7. 风险与控制

### 7.1 风险

- 工作台页面文件较大，视觉重排容易带来局部布局回归。
- 项目库与资产库刚做过功能调整，视觉重排时容易误伤已有交互。
- 全站统一升级可能导致个别移动端间距或高度问题。

### 7.2 控制方式

- 优先做视觉系统基座，再逐页落地。
- 每一页保留现有功能节点，不在视觉改造时顺手扩功能。
- 对工作台主预览区、项目库跳转流、资产库添加弹窗做重点验证。

## 8. 验收标准

完成后应达到：

1. 登录页具有明确品牌感，角色区与表单区风格统一。
2. 顶部壳层更像中枢控制条，桌面端与移动端都稳定。
3. 工作台的主预览区成为视觉中心，整体更开阔。
4. 项目库首页更像项目陈列页，点击后进入项目历史版本页。
5. 资产库更像定稿成果库，图像和 Prompt 资产的区分清晰。
6. 全站背景、卡片、按钮、状态块语言统一。
7. 所有现有功能入口仍然可用。
